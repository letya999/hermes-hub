# История поставок

## 0.1.0 — 2026-09-18

Исходная самостоятельная реализация credential request/approval, provider references, grants/leases,
local/Vault/Kubernetes providers, OAuth PKCE/refresh, runtime materialization/state/proxy, HTTP API и SDK.
Документация организована по memory_bank_setup; проверки и результаты находятся в `.work`.
Версия не объявляет поддержку произвольного MCP и не заменяет приёмку в монорепозитории.
