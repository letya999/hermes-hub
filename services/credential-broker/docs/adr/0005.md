# ADR-0005: Ограниченный OAuth и отсутствие runtime платформ

## Контекст

Нужен код, проверяемый локально, а не ещё одна integration platform.

## Варианты

Fork Nango; mandatory external broker; стандартные Go primitives и явный OAuth subset.

## Решение

Самостоятельный сервис, code+PKCE для предзарегистрированных endpoints, no DCR/device/discovery.

## Последствия

Меньше зависимостей, но расширения требуют отдельного review RFC и реальных provider scenarios.

## Когда пересматривать

Если нужная OAuth библиотека уменьшает security risk; zero-dependency не самоцель.
