# Дополнительная проверка безопасности M10

Дата: 2026-10-11. Этот статический анализ выполнен локально до повторного
разрешения Docker. Последующие интеграционные результаты записаны в state.yaml.

- `just security` прошёл: 0 достижимых уязвимостей Go, 0 уязвимостей импортируемых
  пакетов, 1 находка в требуемом модуле без вызова уязвимого кода; npm — 0.
- Gitleaks проверил содержимое изменённых/новых текстовых файлов с redaction:
  секретов не найдено. Предыдущая проверка Git-истории также прошла.
- Opengrep с правилами проекта завершился. Четыре совпадения полного скана находятся
  в самих YAML-правилах сканера; проверка application paths не дала находок.
  Эти правила не являются полноценным Go SAST и не заменяют gosec.
- Установленный gosec не читает новый Go export data. Проверена конкретная версия
  upstream `v2.29.1-0.20261009120814-7b1b5cebe007` через go run, без глобальной
  установки и без добавления библиотек в приложение. Восемь изменённых пакетов:
  142 файла, ошибок загрузки/типизации 0, 171 совпадение правил. Большинство
  совпадений вне изменённых строк; этот общий backlog не объявляется закрытым.
