# Подключение Telegram и Google: инструкция владельцу

## Что уже подготовлено

На этом компьютере установлены ToolHive и защищённый ToolHub, запущен сервер
чтения Telegram. Доступы лежат вне проекта, в защищённой папке
`C:\Users\User\hermes-hub-private`. Рабочие контейнеры Hermes не переключались.
Вход в ваши аккаунты ещё не выполнен; настоящие письма и сообщения не проверялись.

ToolHive запускает программу-подключение. ToolHub проверяет разрешения и даёт
ей нужный доступ только на время запроса. У Google официальный MCP работает
на серверах Google — скачивать его и запускать в Docker не требуется.

Ничего секретного в чат присылать не нужно: ни пароли, ни коды, ни сессии,
ни API hash, ни OAuth JSON. В этой настройке включается только чтение.
Telegram: ваша пользовательская сессия MTProto; доступны диалоги, группы и
каналы, которые видит сам аккаунт, включая старую историю и серверный поиск.
Боты исключены. Изменения и отправка сообщений этим мастером не включаются.
Google: Gmail, Drive, Docs, Sheets, Slides, Calendar. Отправка сообщений,
изменение документов и удаление данных не включаются этим мастером.

## Откройте окно настройки

1. Откройте Проводник и вставьте в адресную строку
   `C:\Users\User\hermes-hub-private`.
2. Дважды нажмите **Настроить подключения.cmd**.
3. Появится отдельное окно с действиями 1–5. Его не нужно фотографировать или
   пересылать. Docker Desktop должен быть запущен.

## Telegram — вход именно под вашим пользователем

1. Откройте [my.telegram.org/apps](https://my.telegram.org/apps) и войдите своим
   номером. Код для этого сайта приходит в Telegram.
2. Нажмите **API development tools**. Если приложения ещё нет, создайте его:
   **App title:** `Hermes Hub`, **Short name:** `hermeshub`, **Platform:** `Desktop`.
   URL оставьте пустым. Нажмите **Create application**.
3. На странице появятся **api_id** и **api_hash**. Оставьте страницу открытой;
   никому эти значения не отправляйте.
4. В нашем окне введите **3** и Enter. По очереди вставьте API ID, API hash,
   номер телефона с `+7` или вашим кодом страны, затем новый код из Telegram.
   После каждого поля — Enter. Символы скрыты, вставка может не быть видна.
   Если включена двухэтапная проверка, введите её пароль в этом же окне.
5. Дождитесь **Telegram account connected**. Сессию программа сохранит сама,
   проверит, что это именно ваш аккаунт, и уберёт временный файл. Копировать
   сессию не нужно.

После подключения Telegram MCP обращается к Telegram через MTProto от имени
этой сессии, а не через Bot API. `list_dialogs` показывает доступные аккаунту
чаты; `get_messages` умеет листать историю назад по `before_message_id` и
вперёд по `after_message_id`; `search_messages` ищет по истории Telegram,
глобально или внутри выбранного чата. Поэтому это не только «новые сообщения»:
можно последовательно читать старые сообщения до самого начала доступной
истории. В выдаче также отмечаются дата, отправитель, ответы и наличие медиа;
сами файлы не скачиваются автоматически.

Это пользовательский аккаунт, не бот: BotFather и bot token здесь не нужны.
Правила получения API ID/hash описаны в
[документации Telethon](https://docs.telethon.dev/en/stable/basic/signing-in.html).
Если Telegram ограничил попытки входа, не повторяйте их подряд — подождите.

## Google — предварительный доступ, затем разрешение в браузере

Официальные Workspace MCP пока доступны через **Developer Preview**.
Нужны одобрение Google для вашего Workspace-аккаунта и регистрация проекта;
одного OAuth-входа недостаточно. Если у вас только обычный Gmail, не считайте
доступ одобренным: пригодность аккаунта проверяет Google.
[Условия и заявка Google](https://developers.google.com/workspace/preview).

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект
   `Hermes Hub Personal`. В карточке проекта найдите **Project ID** и
   **Project number** — они понадобятся для заявки выше. Дождитесь подтверждения.
2. В этом проекте откройте **APIs & Services → Library**. Включите API Gmail,
   Google Drive, Docs, Sheets, Slides, Calendar и People; затем соответствующие
   Gmail MCP API, Google Drive MCP API, Docs MCP API, Sheets MCP API,
   Slides MCP API, Calendar MCP API. Если MCP API недоступны, сначала решается
   доступ к Preview. Не включайте платные услуги ради обхода ошибки.
3. **Google Auth Platform → Branding → Get started:** имя `Hermes Hub Personal`,
   ваш email поддержки/контакта. **Audience:** Internal для вашей организации,
   иначе External; при External добавьте свой email в **Test users**.
   Затем **Data Access → Add or Remove Scopes → Manually add scopes**:
   вставьте список ниже, нажмите **Add to Table → Update → Save**.

   ```text
   openid
   https://www.googleapis.com/auth/userinfo.email
   https://www.googleapis.com/auth/gmail.readonly
   https://www.googleapis.com/auth/drive.readonly
   https://www.googleapis.com/auth/documents.readonly
   https://www.googleapis.com/auth/spreadsheets.readonly
   https://www.googleapis.com/auth/presentations.readonly
   https://www.googleapis.com/auth/calendar.calendarlist.readonly
   https://www.googleapis.com/auth/calendar.events.freebusy
   https://www.googleapis.com/auth/calendar.events.readonly
   ```

4. **Clients → Create client → Web application.** Имя `Hermes Hub PC`.
   В **Authorized redirect URIs → Add URI** вставьте ровно
   `http://127.0.0.1:8543/callback`. Нажмите **Create**, затем скачайте **JSON** клиента.
5. В нашем окне выберите **1**, укажите скачанный JSON, введите адрес нужного
   Google-аккаунта. JSON останется локально; в чат его не отправляйте.
6. Выберите **2**. Для каждого из шести подключений программа напечатает ссылку.
   Скопируйте её в браузер, выберите нужный аккаунт и разрешите чтение.
   Когда появится **Connected. Close this window**, возвращайтесь к окну настройки.
   Если согласие требует администратора организации, разрешение выдаёт он.

Названия API, OAuth и ограничения опубликованы в
[официальной инструкции Google](https://developers.google.com/workspace/guides/configure-mcp-servers).

## Как понять, что готово

Выберите **4**: появятся подключения и их состояние, без содержимого писем
или переписок. После успешного входа напишите в чат только:
«Telegram подключён» / «Google подключён» и что прочитать для проверки,
например один выбранный диалог или один выбранный документ.

Запущенный сервер сам по себе не означает успешный вход. При ошибке сообщите
название шага, не прикладывая секретный JSON, сессию, пароль, код или скриншот
полей входа. После перезагрузки откройте этот же файл; если службы не восстановились,
попросите проверить их. Не удаляйте рабочие контейнеры самостоятельно.

Доступ Google обновляется вручную: если запросы сообщили об истёкшем токене,
выберите **5**. Если Google отозвал разрешение или закончился срок тестового
OAuth-доступа, нужен повторный вход — попросите подготовить новое подключение.
Не удаляйте локальный Google client-файл: он нужен для обновления доступа.

## Как выключить доступ

Telegram: **Настройки → Устройства → hermes-hub ToolHub → Завершить сеанс**.
Google: **Аккаунт Google → Безопасность → Подключения к сторонним приложениям →
Hermes Hub Personal → Удалить доступ**. Это отключает доступ у самого провайдера.
Попросите также отозвать локальное подключение через `hubctl connector revoke`.
Удаление API hash не заменяет завершение сессии Telegram.
